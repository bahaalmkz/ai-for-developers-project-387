# Календарь звонков

Сервис бронирования времени: владелец публикует типы встреч, гость без регистрации выбирает тип и записывается на свободное время.

## Люди

**Владелец** (Owner):
Единственный хозяин календаря. Задаётся заранее, не регистрируется.
_Avoid_: админ, хост, пользователь

**Гость** (Guest):
Человек, который записывается на встречу без регистрации.
_Avoid_: клиент, посетитель, пользователь

## Бронирование

**Тип встречи** (Event Type):
Предложение владельца: название, описание и длительность.
_Avoid_: услуга, событие, категория

**Слот** (Slot):
Свободный интервал времени, на который можно записаться на выбранный тип встречи. Его длительность равна длительности типа встречи.
_Avoid_: окно, время

**Встреча** (Booking):
Подтверждённая запись гостя на слот. Занятое встречей время недоступно ни для какого типа встречи.
_Avoid_: бронь, заявка, запись (запись — это действие гостя, не сущность)

**Тема разговора** (Guest Topic):
Необязательный однострочный текст гостя (до 200 символов) о том, что он хочет обсудить на встрече. Видна владельцу в списке предстоящих встреч и гостю на подтверждении. Пустая строка — темы нет. Не путать с описанием типа встречи: описание пишет владелец.
_Avoid_: заметка, комментарий, описание

**Часовой пояс владельца** (Owner Timezone):
Единственный часовой пояс сервиса: в нём заданы часы работы и показывается время гостю.
_Avoid_: локальное время, пояс гостя

## Страницы

**Главная страница** (Home Page):
Страница `/`: рассказывает гостю о сервисе и ведёт на страницу записи.
_Avoid_: лендинг, стартовая

**Страница записи** (Booking Page):
Публичная страница `/book`, где гость выбирает тип встречи и слот.
_Avoid_: каталог, форма бронирования

**Раздел владельца** (Owner Area):
Страница `/owner` без авторизации: типы встреч и список предстоящих встреч.
_Avoid_: админка, личный кабинет

**Подтверждение** (Confirmation):
Страница `/book/confirmation`, которую гость видит сразу после записи; данные не сохраняются при перезагрузке.
_Avoid_: чек, квитанция

## Время

**Окно записи** (Booking Window):
Период из 14 календарных дней, начиная с сегодняшнего, в пределах которого гость может занять слот.
_Avoid_: горизонт, период бронирования
