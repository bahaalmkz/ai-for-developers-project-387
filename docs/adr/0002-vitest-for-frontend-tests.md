# Тесты фронтенда — Vitest и Testing Library

Тесты фронтенда пишем на Vitest + React Testing Library (среда jsdom): Vitest работает на конфигурации Vite и не требует отдельной сборки. Тесты запускаются в `mise run check`, а значит и в GitHub Actions.

Рассмотрели Playwright и e2e-тесты: для текущего объёма они слишком тяжёлые (браузеры в CI, медленный прогон). Вернёмся к вопросу, когда появится сквозной сценарий записи.
