# Страницы фронтенда — маршруты React Router

Фронтенд состоит из нескольких страниц (главная, страница записи, позже подтверждение и раздел владельца). Решили использовать `react-router-dom` с адресами `/` (Главная страница) и `/book` (Страница записи), а не переключать страницы состоянием в `App`. Так у каждой страницы свой URL, ссылку на запись можно отправить гостю, а кнопка «назад» работает.

Следствие: сервер на проде должен отдавать `index.html` для неизвестных путей фронтенда (SPA-fallback).
